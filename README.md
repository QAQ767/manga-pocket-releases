# 漫匣 · 安卓下载

漫画搜索、下载、长条 PDF 导出与离线阅读工具。Android 8.0 及以上，不需要 AI 或自建服务器，不依赖电脑开机。

## 安装

前往 [最新版本](https://github.com/QAQ767/manga-pocket-releases/releases/latest)，下载 `manga-pocket-版本号.apk` 并打开安装。已有旧版时直接覆盖安装，保留书架与阅读记录；不要先卸载。

## 应用内更新

0.4.0 开始支持「设置」→「检查应用更新」。打开 App 时最多每 24 小时检查一次，有更新时查看说明、确认下载，校验完成后点击安装。首次可能需要在安卓设置中允许「漫匣」安装应用。

安装包下载需要能访问 GitHub。检查失败可以重试，不影响离线阅读。

## 功能

- 按名称、编号或作者查找漫画，在手机本地下载并导出 PDF。
- 详情显示可复制的作者名与源站更新时间；时间缺失明确标注。
- 内置 JM、MangaDex 官方 API、E-Hentai 公开站、拷贝漫画和示例漫画；可管理自定义 JM 兼容接口和通用 JSON 接口。普通网站需要对应适配。
- MangaDex 提供简中／繁中托管章节，保留汉化组信息；E-Hentai 默认中文搜索，支持完整画廊链接。
- 书架每行三本；长按进入多选，操作栏固定在底部，支持批量隐藏、恢复显示、移动分类和删除漫画。
- 逐章下载，每章完成立即加入同一本书架漫画；中断后保留已完成章节，继续时跳过它们。
- 章节可按每 10 章一个区间选择，支持多选区间和逐章选择。「下载 → 按区间下载」可重选已有作品，确认停止未完成任务后调整范围。
- 删除已完成下载记录保留漫画；删除未完成记录会终止任务、清理未完成资源，本次及之前已完成的章节保留。漫画新章节追加到同一本。
- 章节内向下连续阅读，换章时点击下一章。
- 书架「更多」支持显示隐藏漫画、检查全部漫画更新。
- 书架「更多 → 管理分类」自建、改名或删除分类；长按漫画「移动到分类」。删除分类保留文件，追加章节沿用原分类。

- 本地 PDF／图片 ZIP 导入：书架「更多 → 导入漫画」，PDF 按文件分章，ZIP 按图片文件夹分章、按数字页码排序。详情「追加导入」补充同一本，原文件保留。
- 已下载的应用更新仍可重新检查，安装地址与文件名带版本标识。

当前版本 [0.9.0](https://github.com/QAQ767/manga-pocket-releases/releases/tag/v0.9.0)。E-Hentai 更新以完整画廊版本作为新章节追加，可能包含旧页面；没有提供可靠更新时间时明确显示缺失。仅使用公开站，不提供 ExHentai 登录。拷贝漫画保留源站机翻标记；本地导入支持未加密 PDF 和包含 JPG／PNG／WEBP 的 ZIP，不支持 RAR。

本仓库用于公开发布正式安装包、更新说明和校验信息。源码在所有者的私有仓库维护，签名密钥、密码和个人漫画数据不上传。

网站适配和图片还原参考 JMComic-Crawler-Python，开源许可见 [NOTICE.txt](NOTICE.txt)，也可以在 App 的开源致谢中查看。
