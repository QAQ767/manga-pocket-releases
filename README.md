# 漫匣 · 安卓下载

漫画搜索、下载、长条 PDF 导出与离线阅读工具。Android 8.0 及以上，不需要 AI 或自建服务器，不依赖电脑开机。

## 安装

前往 [最新版本](https://github.com/QAQ767/manga-pocket-releases/releases/latest)，下载 `manga-pocket-版本号.apk` 并打开安装。已有旧版时直接覆盖安装，保留书架与阅读记录；不要先卸载。

## 应用内更新

0.4.0 开始支持「设置」→「检查应用更新」。打开 App 时最多每 24 小时检查一次，有更新时查看说明、确认下载，校验完成后点击安装。首次可能需要在安卓设置中允许「漫匣」安装应用。

安装包下载需要能访问 GitHub。检查失败可以重试，不影响离线阅读。

## 功能

- 按名称或编号查找漫画，在手机本地下载并导出 PDF。
- 书架每行三本；长按可以隐藏、恢复显示或删除整本漫画。
- 删除下载记录保留漫画；漫画新章节追加到同一本。
- 章节内向下连续阅读，换章时点击下一章。
- 书架「更多」支持显示隐藏漫画、检查全部漫画更新。

本仓库用于公开发布正式安装包、更新说明和校验信息。源码在所有者的私有仓库维护，签名密钥、密码和个人漫画数据不上传。

网站适配和图片还原参考 JMComic-Crawler-Python，开源许可见 [NOTICE.txt](NOTICE.txt)，也可以在 App 的开源致谢中查看。
